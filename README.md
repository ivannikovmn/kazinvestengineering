# KazInvestEngineering Test Task

## Setup

### Backend

```bash
cd backend
npm init -y
npm install express
npm install --save-dev nodemon
npm install morgan
```

### Run backend

```bash
npm run dev
```

### Backend URL

```text
http://localhost:3000/
```

### Frontend

cd frontend
npm install
npm run dev

### Run frontend

```bash
npm run dev
```

### Frontend URL

```text
http://localhost:3001/
```

## Stack
- Node.js + Express + Morgan + Nodemon
- Next.js + React + TypeScript
- Tailwind CSS
